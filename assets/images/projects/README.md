# Project artwork

Project card artwork refreshed from the public sources below on 2026-10-15.
Raster assets are resized to at most 800 pixels wide and encoded as WebP
(quality 82, metadata stripped). SVG artwork stays vector.

Frames share a 16:9 aspect ratio. Screenshots, share images, plugin previews,
and theme previews fill the frame edge to edge with `object-fit: cover`.
Logos use `contain` with padding. Image dimensions and descriptive alt text live
in the project data alongside each asset path.

Plugin previews come from the published project repositories, including their
synthetic demo content. MXC and devhost use original SVG cards with documented
commands because they have no dedicated share artwork.
